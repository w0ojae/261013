# 초록 사이 — 나의 작은 건물

사용자가 제작한 수정본 `건물2.glb`를 중심으로 만든 Three.js 디오라마입니다. 창문 빗물은 사용자가 지정한 Over-the-Window의 물리·물방울 코드를 바탕으로 3D 창문에 맞게 통합했습니다.

## 실행

Node.js가 설치되어 있다면 이 폴더에서 `node scripts/serve.mjs`를 실행하고 http://127.0.0.1:5180/ 을 여세요. 별도 패키지 설치는 필요하지 않습니다.

## 기능

- 수정본 건물 형상과 46개 원본 재질, 내부와 외부가 보이는 투명 유리
- 절차적 정원, 나무, 꽃, 가로등, 떠 있는 지형
- 낮·노을·밤 시간 슬라이더, 10분 동안 흐르는 하루
- 맑음·구름·비, GPU 빗줄기와 야간 반딧불
- 비 오는 날의 젖은 외벽·지붕·정원, 웅덩이 반사·파문·작은 물튀김, 조명 번짐
- 시점 전환, 확대, 자동 회전, 전체 화면
- 1층 카페 / 2층 창가 1인칭 모드, 실내 조명
- 비 오는 날 실내·실외 1인칭에서 함께 보이는 창문 바깥면 빗물, 유리 너머 풍경의 굴절
- 층 선택 시 약 0.9초의 어두워졌다 밝아지는 전환, Esc로 즉시 취소
- 마우스·터치 드래그로 시선, WASD·방향키·화면 화살표로 이동
- 벽·가구 충돌 방지, 층 선택, 외부 보기 버튼 / Esc 복귀
- 브라우저에서 합성하는 자연 소리(기본 꺼짐)

`dist/assets/building2.glb`는 `건물2.glb` 파일 그대로 보존됩니다. 수정본의 내보내기 높이 차이는 실행할 때 보정하여 창문·조명·실내 시점을 맞춥니다. Three.js 0.180.0과 MIT 라이선스는 `dist/vendor/`에 포함됩니다. Noto 웹 폰트는 Google Fonts에서 불러오며 연결이 없으면 시스템 글꼴로 표시됩니다. 실행에 외부 API 키나 모델 생성 서비스가 필요하지 않습니다.

건물 배치값은 `dist/building-placement.js`에서 관리하며, 현재 낮춤량은 전체 접지 조정량의 2/5입니다. 건물·1/2층 시점·비 차단 높이·건물 주변 빗물 조명이 같은 높이 보정을 공유합니다. 창문과 실내 조명은 건물 부모를 따라 이동하며, 정원과 돌길·웅덩이의 높이는 유지합니다. `node --run test`는 원본 GLB 형상의 배치 비율, 실내 시점 정렬, 이동 충돌과 빗물 물리 회귀 검사를 실행합니다.

실내는 창가와 통로의 안전한 구역에서 이동합니다. 계단으로 층을 오르는 대신 상단의 층 선택 버튼을 사용하세요. 이동 버튼은 누르고 있는 동안 움직이고, 키보드로 버튼을 실행하면 짧게 이동합니다. 건물 안에는 비가 내리지 않도록 지붕 범위를 적용했습니다.

창문 빗물은 원본의 CodropsPhysics, WaterMap, Heartfelt 표면 필드와 변형·마찰·물길 계산을 유지합니다. `dist/glass-panes.js`의 유리는 원본 GLB 창틀 바깥면 바로 뒤에 놓이며, 각 유리의 한 물방울 지도를 안과 밖에서 공유합니다. 창문별 고정 좌표에서 30Hz로 계산하고, 실내 층 선택과 관계없이 카메라에 보이는 유리를 갱신합니다. 화면 밖의 유리는 상태를 보존한 채 일시 정지합니다. 바람 계산, 음악 연결, 영상 배경, 유리 닦기 조작은 포함하지 않았습니다. 유리 너머 풍경을 한 번 공유 캡처한 뒤 GPU에서 흐림과 굴절을 처리합니다. 캡처한 깊이를 창문 평면과 비교해 창틀·가구를 가리고, 굴절이 가까운 프레임을 끌어오지 않도록 제한합니다. 실내·실외 이동·층 전환·화면 크기 변경 시 물방울을 다시 생성하지 않습니다. 전체 디오라마 시점과 맑음·구름에서는 보통 유리로 복귀합니다.

효과의 출처와 라이선스는 `dist/rain/THIRD_PARTY_NOTICES.md`를 확인하세요. Heartfelt 기반 부분은 원본에 명시된 CC BY-NC-SA 3.0을 따릅니다.

외부 비 효과는 `dist/weather/`의 독자적 셰이더와 절차적 표면으로 구현했습니다. Unseen WebGL Rain은 분위기 참고용이며 그 사이트의 코드·텍스처·이미지는 포함하지 않습니다. 단일 Three 렌더러에서 GPU 빗줄기, 저해상도 풍경 굴절, 제한된 크기의 바닥 반사, 조명 번짐을 공유합니다. 실내 가구·유리·전구는 젖은 재질 대상에서 제외하고, 건물 아래의 비와 웅덩이는 가립니다. 바람 시뮬레이션은 추가하지 않았습니다. 모바일은 비 입자 수와 캡처 해상도를 줄이고, 움직임 감소 설정은 외부 비와 파문을 멈춥니다. 비를 끄면 기존 표면으로 즉시 복귀합니다.

1층 문 가까이에서 출입 버튼을 누르면 검은 디졸브 뒤 정원 1인칭 산책으로 이어집니다. 밖에서는 오른쪽 벽의 반쯤 열린 문틈 앞에 접근하면 카페로 돌아올 수 있습니다. 입장 안내는 옆의 고정된 정면 개구부에서 뜨지 않도록 좁은 직사각형 범위를 사용합니다. 실외 이동은 정원 가장자리와 건물·나무·전등·가구 충돌을 처리하고, 원본 토대 표면을 따라 눈높이를 조정합니다. Esc 또는 전체 보기로 디오라마 시점에 복귀합니다.
